# 原生课表外观插件（API 6）

`TimetableAppearanceService.KEY` 由启用的内置课表插件提供。设置类界面插件在 `plugin.json` 声明 `capabilities: ["hita.ui.timetableAppearance"]`，从市场「我的插件」卡片打开。运行时设置插件通过此服务修改原生课表，不依赖数据库或课表 Fragment，也不注册另一份课表页面。

- `observe()`：外观快照；包含卡片不透明度 0–100、背景模糊度 0–30、暗色遮罩 0–80，以及宿主管理的图片状态和修订号。
- `update(settings)`：写入经过范围限制的显示参数。图片状态由宿主决定，调用者不能伪造图片路径或修订号。
- `importWallpaper(stream)`：**调用方必须切到后台线程**（服务内部同步执行）。读取最多 20 MB 的图片，校验后按 EXIF 方向旋转、采样至长边不超过 1600 像素，以 PNG 原子写入宿主私有目录；失败保留旧图。输入流由调用者关闭。
- `openWallpaper()`：**调用方必须切到后台线程**；返回的流由调用者关闭。图片不会进入课表导出、云同步或网络上传，并已从 Android 云备份/设备迁移中排除。
- `clearWallpaper()` / `reset()`：清除图片，或同时恢复默认外观。

原生 `TimetableFragment` 把壁纸层置于现有日期栏、时间标尺和课程下方，只模糊背景图。Android 12+ 使用 RenderEffect；Android 6–11 对限长缩略图执行后台两次盒式模糊。透明度变化直接更新课程样式，壁纸文字使用阴影辅助阅读。

设置属于宿主的课表偏好，关闭、停用或卸载设置插件后保留；设置插件提供恢复默认。内置课表插件清数据时一并清除壁纸和外观设置。

验收重点：图片选择取消/错误文件/超限文件、替换失败保留旧图、重启恢复、快速拖动滑杆、深浅主题、切周时图层位置、Android 6–11 模糊回退，以及内置课表停用/恢复。桌面小组件不使用壁纸。
