# 0.7.2 调研手册与开发方案：市场分区、交互恢复与 HITA_L 复刻

> 状态：0.7.2 已发布（tag `v0.7.2`，commit `b066e40`）；M1–M5 已开发。  
> 基线：`v0.7.1`（`e9ed510`），分支 `feat/hita-android-shell`  
> 范围：使用反馈中的 5 项问题；不新增插件生态能力，不重写模型/后端

## 1. 目标

0.7.2 只做“使用中暴露的问题”：

1. 插件市场：整合包从插件列表中独立成分区；
2. HITA_Android 时间表：可下滑看到晚间课程，周切换有动画；
3. HITA_Android 今日：课程卡可点击，保留上游的功能与动画；
4. 全 Shell 交互审计：按钮功能、点击反馈、页面/切换动画是否还在；
5. HITA_L 整合包：UI 与行为对齐 HITA_L 1.5.3，而不是当前宿主简化版。

## 3. 调研结论

### 3.1 市场整合包未独立

现状：

- `FragmentPluginMarket.renderDiscover()` 把 `Preset`、`Ui`、`Dex` 统一塞进 `discoverContainer`；
- 一个卡片流里既有整合包又有插件，仅靠 `meta` 文本“整合包”区分；
- 布局没有“整合包”/“插件”分区标题，也没有独立容器。

影响：

- 整合包被插件淹没，切换入口不清晰；
- 搜索时两类结果混排。

方案：

- 在 `fragment_plugin_market.xml` 的 Discover 区域增加：
  - `preset_section_title` + `preset_container`；
  - `plugin_section_title` + `discover_container`（仅插件）。
- `renderDiscover()` 分开渲染；搜索同时过滤两区；
- 两区都为空时才显示 `discover_empty`；
- 整合包区只有存在结果时显示标题，插件区同理；
- 保持现有“应用/切换/使用中”逻辑不变。

验收：

- 打开市场 → 查询并下载，先看到独立“整合包”区；
- 下方才是“插件”区；
- 搜索整合包/插件分别只影响对应区；
- 无结果时空态正确；
- 应用/切换整合包行为与 0.7.1 一致。

### 3.2 时间表不能下滑、周切换无动画

现状（`PresetShellActivity.TimetablePage`）：

- 网格用 `Row(Modifier.height(hourHeight * 12))`，父 `Column` 没有 `verticalScroll`；
- 屏幕高度不足时，晚间课程被底栏裁掉，无法继续下滑；
- 周切换在 `pointerInput` 中直接 `weekOffset += 1/-1`，没有过渡动画；
- 横向手势与纵向滚动没有协调。

方案：

- 将时间表内容放入 `verticalScroll`，并给底部预留 dock 高度；
- 保留时间列/7 天列结构，滚动时标题栏固定；
- 周切换改为 `AnimatedContent` 或 `HorizontalPager`：
  - 左右滑动/点击切换时，旧周淡出、新周滑入；
  - 动画期间禁用重复切换；
- 处理手势冲突：
  - 横向拖动超过阈值才切周；
  - 纵向拖动交给滚动；
  - 不要吞掉课程卡点击。
- 校验 8:00–21:00、19:00 后课程、跨节课程、空课表。

验收：

- 时间表可连续下滑看到 19:00–21:00；
- 滚到底不被 dock 永久遮挡；
- 左右切周有可见动画；
- 快速连续滑动不产生错周/空白；
- 周标题、课程卡时间位置仍正确。

### 3.3 今日课程卡不可点击

现状：

- `TodayEventRow` 只是 `Row` + 文本，没有 `clickable`/`onClick`；
- 上游 `FragmentTimeLine`/`TimelineListAdapter` 的课程/事件卡可打开详情；
- 当前 Today 页没有点击反馈和跳转。

方案：

- 给 `TodayEventRow` 增加 `clickable`（保留 ripple）；
- 点击打开课程/事件详情：
  - 优先复用上游 `EventItemFragment`/`TimetableDetailActivity`/`SubjectActivity` 的契约；
  - 不新增第二套详情页；
- 增加按下/抬起视觉反馈；
- 校验课程、已结束课程、空态。

验收：

- 点击今日课程卡有 ripple；
- 打开正确的课程/事件详情；
- 返回后 Today 状态不丢；
- 空态无点击区域。

### 3.4 全局按钮功能与动画审计

现状：

- Shell 底栏有 `animateDpAsState` 指示器；
- 部分入口仅 `clickable` 无 ripple；
- 时间表切周无动画；
- Today 无点击；
- 资讯/更多/助手的卡片/按钮需要逐项确认。

方案：

建立交互矩阵（页面 × 入口 × 期望动作 × 当前状态 × 证据）：

- 底栏 6 tab：选中指示器、页面切换；
- 待办：添加、完成、编辑、日期切换、跳日期；
- 今日：课程卡点击、日期切换；
- 时间表：纵滑、横滑周切换、分享、主题、课程卡；
- 助手：发送、附件、会话切换、新建、删除、设置；
- 资讯：博客/校园通知切换、卡片点击、详情返回、失败重试；
- 更多：用户卡、课表管理、教务功能各行、插件市场、设置、深浅色。

对缺失项统一补：`clickable`/`onClick`、ripple、必要过渡；不为了动画而阻塞功能。

验收：

- 每个可点击元素在设备上至少点击一次；
- 无“点了没反应”的入口；
- 关键切换有可见动画；
- 返回栈正确。

### 3.5 HITA_L 1.5.3 不像

现状：

- 当前 HITA-L 走宿主原生 `MainActivity`，但经过 0.6/0.7 重构后，部分 UI/行为与 HITA_L 1.5.3 偏离；
- 参考仓库已拉取：`/tmp/HITA_L_ref`，tag `v1.5.3`，commit `6305d6e`；
- 需对齐的不只是颜色，还包括：
  - 底栏/导航结构；
  - 今日时间轴与课程卡交互；
  - 时间表滚动/切周/课程卡；
  - 功能中心与市场入口；
  - 主题、字体、动画。

方案：

1. 源码映射：对 `MainActivity`、`FragmentTimeLine`、`TimelineListAdapter`、`TimetableFragment`、`TimetableWeekView`、`NavigationFragment`、`MainTabBar`/主题资源做文件级差异表。
2. 先恢复结构（tab/页面/入口顺序），再恢复交互（点击/滚动/动画），最后视觉。
3. 以 HITA_L 1.5.3 为唯一参考，不把 HITA_Android Shell 的结构带入 HITA-L。
4. 建立 HITA-L 回归基线（今日/时间表/功能中心/市场），确保不污染 HITA_Android 路径。

验收：

- HITA-L 切换后底栏、页面、入口与参考一致；
- 今日课程可点击、时间表可滚动/切周；
- 功能中心/市场入口行为一致；
- HITA_Android 切换不受影响。
