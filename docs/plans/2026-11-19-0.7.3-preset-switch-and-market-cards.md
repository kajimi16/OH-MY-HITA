# 0.7.3 插件市场体验优化

## 1. 整合包切换

问题：切换成功后市场 Activity 仍在前台，底层 Shell/MainActivity 没有重新路由；用户看到“没有反应”。

设计：

- 应用整合包增加显式状态机：
  `IDLE -> PREPARING -> RESOLVING -> APPLYING -> SAVING -> LAUNCHING -> IDLE`
- `PluginMarketViewModel` 暴露 `applyProgress`（0–100 + 文案）和一次性 `presetSwitch` 事件。
- 成功后由市场启动目标 UI：
  - target shell 非空 → `PresetShellActivity`；
  - target shell 为空 → `MainActivity`（HITA-L 原生）；
  - 关闭市场 Activity。
- 失败保留旧组合，关闭进度窗口并显示错误。
- 切换时按 CompositionResolver 停用旧 preset 独有 UI/内置插件，启用目标 preset refs。

## 2. 市场卡片

问题：卡片高度由文字撑开，网格不整齐。

设计：

- 卡片固定高度 128dp；
- 名称单行，描述最多两行并 ellipsize；
- 更多信息通过点击卡片打开预览/详情；
- 按钮/开关固定在右侧，不参与高度扩张。

## 3. 实现与验收

- 已实现 `applyProgress` 与 `presetSwitch` 事件；市场成功后启动目标 Shell/MainActivity 并 `finish()`。
- 已实现不可取消的“切换整合包”进度窗口；最短展示 650ms。
- HITA-L → HITA_Android：设备验证进入 6 tab Shell；`disabled_ids` 为空。
- HITA_Android → HITA-L：设备验证进入 MainActivity；`ui_plugins.xml` 的
  `disabled_ids` 实际包含 17 个 HITA-Android UI 插件。
- 目标页使用 `CLEAR_TOP | SINGLE_TOP`，不再新开任务；目标 shell 从
  `PresetStateStore.activeShell` 读取（包含宿主映射）。
- 卡片固定高度 128dp；内层横向容器与左右列均 `match_parent` 并垂直居中；
  名称 1 行、描述 2 行 ellipsize；详情仍通过卡片点击打开。
- 进度窗口截图：`app/build/progress_final.png`；卡片截图：`app/build/market_final_cards.png`
  （本地验证产物，未入库）。

## 4. 今日页课程卡点击

问题：顶部蓝色“今日课程”卡画了展开箭头但没有点击处理；课程行只有白色卡片区域可点。

对齐 HITA_Android：点击顶部卡片展开/收起下一节课程面板，箭头旋转 180°；
没有下一节时显示“接下来没事了 / see you”。课程行改为整行可点，继续打开
`TimetableUiService.showEventInfo` 底部详情。

验证截图（本地产物，未入库）：
- 展开：`app/build/today_expanded.png`
- 收起：`app/build/today_collapsed.png`
- 课程行详情：`app/build/today_row_sheet.png`

## 5. 更多页抽屉对齐 HITA_Android

原版抽屉：教务头像 + 登录状态头部，下面依次是“课表管理 / 用户与隐私协议 / 关于HITSZ助手”。
当前抽屉只有文字和箭头，缺少头像与隐私协议，并混入设置类入口。

已改为：
- 96dp 教务头像与昵称/登录状态，整块可点击进入教务登录；
- 三个原版入口，使用原版图标与顺序；
- “用户与隐私协议”打开 `UserAgreementDialog`；
- 其他设置入口保留在更多页，不重复塞进抽屉。
