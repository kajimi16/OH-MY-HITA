## 3. 本轮补做的像素验收

### 3.1 更多页抽屉

基准确认：设备上 `com.stupidtree.hitax` 是 **1.5.2**，不是文档基准；
真正的 HITA_Android 3.1.2 是 `cn.limpu.hita`（versionCode 2026103101）。
本节已全部改用 `cn.limpu.hita` 重测，先前基于 1.5.2 的 3.257% 结论作废。

3.1.2 抽屉内容：


实现已改为同一结构与顺序，账号信息来自 `EasService.accountName/accountSubtitle`。

## 5. 复审结论

1. 已关闭项维持原状态，不重复优化 HITA-L 三页、资讯残差、视频 429、header/dock。
2. 更多页抽屉已按真正的 `cn.limpu.hita` 3.1.2 重做；内容/尺寸/bounds 通过，
   逐行像素 3.5%–9.0%，整面板因登录态不同不记通过。
3. 成绩插件页未通过像素验收；TopAppBar 已补，但标题/动作/空态结构仍不同。
4. 其余未比较对象要么没有上游等价页面，要么缺少登录态/等价数据，不能记为通过。

## 6. 下一步优先级

1. 成绩插件页：定义插件页面标题与工具栏动作契约，统一未登录卡片。
2. Shell 资讯详情/门户登录：构造上游同数据态后再做像素。
3. 更多页内容区/抽屉：构造与上游相同的登录态后重算整面板像素。
4. 迁移的 EAS 子页面：抽样做像素，而不是继续声称“结构一致”。
