# 0.8.0 调研：动效、音效与插件依赖

> 日期：2026-11-20  
> 范围：只调研当前独立仓库 `kajimi16/OH-MY-HITA` 的 API 与运行时，不实现 0.8.0。

## 1. 结论

| 问题 | 当前答案 |
|---|---|
| 宿主 API 能修改应用动效/动画吗 | **不能统一修改**。宿主 Shell 动画硬编码；插件只能在自己的 Compose 内动画 |
| 宿主 API 能修改音效吗 | **没有音效 API**。只有通知渠道的固定振动/系统声音；插件可直接调 Android 音频，但不受宿主管理 |
| 插件之间能声明依赖吗 | **部分可以**：构建期/dex 插件可声明 ServiceKey 级 `requires`；UI 插件不行 |
| 能声明“基于哪个整合包界面”吗 | **不能**。没有 preset/shell 字段，也没有兼容性校验 |
| 能声明依赖其他插件 id/版本吗 | **不能**。只有服务名，没有插件 id 或版本范围 |

## 2. 现有能力

### 2.1 动效与动画

当前 `ThemeController` 只暴露视觉 token：

```kotlin
data class ThemeTokens(
    val cornerRadiusDp: Float,
    val spacingDp: Float,
    val glassAlpha: Float,
)
```

没有 duration、easing、motion scale、respect-reduced-motion 等字段。

宿主 Shell 的动画直接写在 `PresetShellActivity`：

- tab 切换：`AnimatedContent` + `fadeIn/fadeOut`
- 抽屉：`AnimatedVisibility` + slide/fade
- 今日课程卡展开：`AnimatedVisibility` + 箭头旋转
- 时间表切周：`AnimatedContent` + 滑动/淡入
- 市场切换进度：固定进度窗口

这些都是编译期常量，插件无法替换或参数化。

运行时 UI 插件可以在自己的 Compose 代码里使用任意 animation API；例如
`plugin-ui-resource` 自己实现了 400ms 列表入场动画。但这是**插件内部动画**，
不是宿主动效 API，也不能让插件修改宿主 tab/drawer 的动画。

可用的相关能力只有：

- `ThemeController.setNightMode/colorPreset/themeStyle/fontScale`
- `TimetableAppearanceService`：壁纸、卡片透明度、模糊、遮罩
- `ThemeController.tokens()`：圆角、间距、玻璃透明度
- `PluginUiHost`：`service`、`arguments`、`close`，没有动画/动效服务

### 2.2 音效与触感

当前 API 没有：

- `SoundService` / `AudioService` / `FeedbackService`
- 音效事件枚举
- 音量、静音、可访问性策略
- 插件自定义音效资源的注册/播放接口
- 宿主动效/音效的全局开关

宿主实际存在的只有通知渠道：

- 课程提醒：`CourseReminderWorker` 创建 `NotificationChannel`，固定 `enableVibration` 和振动 pattern
- 直播课：固定高重要性 channel
- 提醒：固定振动
- 成绩提醒：固定 channel

这些是通知行为，不是可由插件或整合包配置的 UI 音效。

旧 View 页面有零散 `HapticFeedbackConstants`，但也没有统一服务。

### 2.3 插件依赖

#### 内核层

`PluginDescriptor`：

```kotlin
data class PluginDescriptor(
    val id: String,
    val requires: Set<String> = emptySet(), // ServiceKey.name
    val provides: Set<String> = emptySet(), // 仅诊断
    val origin: PluginOrigin = PluginOrigin.UNKNOWN,
    val version: String? = null,
)
```

`PluginHost.install` 的行为：

1. 计算 `requires` 中缺失的服务；
2. 缺失时放入 `pendingPlugins`，不激活；
3. 其他插件提供新服务后 `drainPending()` 重试；
4. 服务齐备后激活；
5. `provides` 只用于诊断，不作为激活依据。

这能表达：

```text
插件 A 依赖 ServiceKey("hita.eas")
插件 B 提供 ServiceKey("hita.eas")
```

但不能表达：

- 依赖插件 id `com.example.ui.anime`
- 依赖版本范围
- 可选依赖
- 循环依赖检测
- UI 插件依赖

#### 市场/索引层

`MarketPlugin` 有 `requires: Set<String>`，用于 dex 插件；安装时传入
`PluginDescriptor.requires`。

`UiMarketPlugin` 没有 `requires` 字段；`UiPluginManager.Metadata` 也没有。
UI 插件只校验：

- `apiVersion` / `minHostApi` / `maxHostApi`
- `apiAbi`
- `minSdk`
- `composeVersion`
- `capabilities` / `mainTabs`

因此 UI 插件可以通过 `PluginUiHost.service(key)` 取服务，但**不能声明自己依赖它**，
缺服务时只能拿到 `null`。

#### 整合包层

`PresetPluginRef.required` 是**组合级必选**：

- 应用整合包时，必选插件缺失/停用会阻止对账；
- 它不是插件之间的依赖声明。

`MarketPreset` 有 `shell`、`tabs`、`plugins`，但 UI 插件元数据没有：

- `presetId` / `targetShell`
- `requiresPreset`
- `supportedPresets`
- `uiContractVersion`
- `themeStyle` / `layoutVersion`

所以插件无法声明“我在 HITA_Android 3.1.2 的 6 tab 界面下开发”，
宿主也无法在切换到 HITA-L 后标记它不兼容。

## 3. 0.8.0 建议

### 3.1 Motion API

建议在 API 9 增加 `MotionController`，或扩展 `ThemeTokens`：

```kotlin
data class MotionTokens(
    val enabled: Boolean,
    val durationShortMs: Int,
    val durationMediumMs: Int,
    val durationLongMs: Int,
    val easing: String,          // standard / emphasized / linear
    val scale: Float,            // 0..1，系统 Animator duration scale
)

interface MotionController {
    fun tokens(): MotionTokens
    fun observe(): LiveData<MotionTokens>
    fun setProfile(profileId: String): Boolean
    fun profile(): String
}
```

用途：

- 宿主 Shell 的 tab/drawer/week/progress 动画读取同一组 token；
- 插件内部动画读取 token，保证速度/缓动一致；
- 尊重系统“移除动画/动画时长 0”和辅助功能设置；
- 预设可以声明 `motionProfile`，但不能绕过系统无障碍设置。

不建议让插件直接替换宿主 Shell 的 `AnimatedContent` 实现；先提供 token 和 profile，
避免 UI 插件把宿主布局改坏。

### 3.2 Feedback API（音效 + 触感）

建议统一为语义事件，而不是让插件直接持有 `SoundPool`：

```kotlin
interface FeedbackService {
    fun play(event: FeedbackEvent)
    fun haptic(type: HapticType)
    fun observeSettings(): LiveData<FeedbackSettings>
}

enum class FeedbackEvent { TAB, CLICK, SUCCESS, ERROR, NOTICE }
```

宿主负责：

- 音效资源、音量、静音、耳机/铃声模式；
- 触感强度与系统设置；
- 插件不能绕过全局静音；
- 通知音仍由通知渠道控制，不混入 UI 音效。

可选扩展：预设提供 `soundProfile`，只改变宿主已注册的音效映射，不允许任意文件路径播放。

### 3.3 插件依赖声明

建议同时支持两类依赖，避免把“服务依赖”和“插件依赖”混在一起：

```json
{
  "requires": {
    "services": ["hita.eas"],
    "plugins": [
      {"id": "com.example.base", "minVersion": "0.2.0", "optional": false}
    ],
    "hostApi": 9
  }
}
```

内核增加：

- 插件 id 依赖图；
- 版本范围；
- 可选依赖；
- 循环依赖拒绝；
- 缺失时 waiting/blocked 状态进入 diagnostics；
- 卸载 provider 时不自动卸载 dependents，只标记 degraded。

UI 插件复用同一份 descriptor，而不是只校验 `apiVersion`。

### 3.4 整合包/界面绑定

建议给 UI 插件增加**软约束**：

```json
{
  "uiContract": {
    "targetPreset": "hita-android-3.1.2",
    "supportedPresets": ["hita-android-3.1.2"],
    "themeStyles": ["classic", "cyber"],
    "layoutVersion": 1
  }
}
```

语义：

- `targetPreset`：开发时的参考界面；
- `supportedPresets`：已知兼容范围；
- 不匹配时市场显示“未验证”，宿主给警告，但不自动卸载；
- 若插件硬依赖某个服务/布局，用 `requires.services` 或新增 `requires.layoutContract` 表达；
- 切换整合包时，插件进入 `degraded` 而不是被静默删除；
- 插件详情页显示“基于 HITA_Android 3.1.2 开发”。

不建议把 `requiresPreset` 做成硬失败：用户手工安装的插件不应在切换预设时被自动卸载；
硬依赖应显式、可诊断、可回退。

## 4. 兼容与风险

- API 版本需要升到 9，旧插件通过 `requiresApi <= host` 继续可用；
- 新字段全部可选，缺省等价旧行为；
- Compose 插件仍受 `composeVersion` 与宿主 Compose 运行时约束；
- 不能让音效/动画绕过系统的“移除动画/静音/辅助功能”；
- 插件目前与宿主同进程、拥有宿主权限；API 只是契约，不是安全沙箱；
- 依赖图需要避免循环等待；建议用 DAG + 波次激活 + diagnostics；
- 预设切换要区分“组合必选缺失”和“插件 UI 未验证”。

## 5. 分期建议

| 阶段 | 内容 | 验收 |
|---|---|---|
| M1 | MotionTokens + 宿主 Shell 接入 | 系统动画缩放 0 时无动画；插件读到同一 token |
| M2 | FeedbackService + 静音/触感设置 | 全局静音生效；插件无法绕过 |
| M3 | 插件 id 依赖 + 版本范围 + diagnostics | 缺失/循环/降级有诊断，不破坏其他插件 |
| M4 | UI contract + 预设兼容提示 | 切换 HITA-L/HITA-Android 时显示“未验证”，不自动卸载 |

## 7. 第一阶段实现状态（2026-11-20）

已完成本地实现，未发布：

- `HITA_API_VERSION = 9`，ABI 已重新生成。
- 新增 `MotionController` / `MotionTokens`：
  - `standard` / `expressive` / `reduced` profile；
  - 读取系统 `ANIMATOR_DURATION_SCALE`；
  - Shell tab 切换、抽屉、今日卡、时间表切周使用统一 token。
- 新增 `FeedbackService`：
  - 语义事件 `TAB/CLICK/SUCCESS/ERROR/NOTICE`；
  - 触感类型与全局开关；
  - 默认关闭，避免改变现有用户行为。
- `VIBRATE` 权限已加入 Manifest。

仍未实现：

- 插件 id 依赖、版本范围、UI 插件 `requires`；
- `uiContract` / `targetPreset` 兼容校验；
- 动效/反馈设置 UI；
- 市场进度窗口等剩余局部动画接入 MotionTokens。
