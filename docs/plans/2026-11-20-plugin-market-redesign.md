# 插件市场 UI/UX 改版设计

日期：2026-11-20  
范围：`PluginMarketActivity` 内的插件市场（`FragmentPluginMarket`），不改主界面、插件加载器和插件协议。

## 1. 目标

把当前“双列卡片 + 内嵌搜索 + 弹窗详情”的市场，改成可扫描、可筛选、状态明确的移动端商店：

- 单列自适应行，插件图标/字形、名称、说明、版本和动作分层。
- 搜索与筛选固定在内容顶部，不再随列表滚走。
- 探索、已安装、更新分开；更新有数量徽标。
- 插件和整合包都有可滚动的详情面板。
- 插件源独立管理，不再依赖多层文本弹窗。
- 加载、空结果、失败、切换进度都有明确状态。

## 2. 非目标

- 不新增远程服务、账号、评分或评论。
- 不改变索引格式、安装校验、信任模型和整合包解析。
- 不重写 `PluginMarketViewModel` 的安装/组合逻辑。
- 不修改主界面底栏、更多页或非市场页面。

## 3. 信息架构

```text
插件市场
├─ 工具栏：返回、标题、刷新、更多
│  └─ 更多：插件源、自定义插件指北
├─ 固定搜索栏：搜索 + 筛选
├─ 固定 tab：探索 / 已安装 / 更新（徽标）
├─ 状态区：结果数、刷新提示、切换进度
└─ 内容
   探索
   ├─ 可更新（有更新时）
   ├─ 整合包
   └─ 全部插件
   已安装
   ├─ 可更新（有更新时）
   ├─ 已启用
   └─ 已停用
   更新
   └─ 全部可更新项 + 全部更新
```

### 3.1 行模型

- 单列；行最小高度 76dp，自适应，不固定高度。
- 左侧 44dp 图标；无 `logo` 时显示插件名首字/首字母的圆形字形。
- 文本区：名称 16sp 半粗；说明 13sp，最多一行；元信息 12sp。
- 尾部：
  - 可执行动作：安装/更新/打开，使用文字按钮或小填充按钮。
  - 状态：已安装/使用中/已停用，使用轻量 chip，不使用主按钮。
  - 开关：内置插件、已安装界面/逻辑/APK 插件。
- 行点击进入详情；动作与开关独立消费点击。

### 3.2 详情面板

全高底部面板，包含：

- 图标、名称、版本、类型、作者。
- 状态/信任/更新 chip。
- 描述、更新日志、标签、体积、最低 API、更新时间。
- 整合包：包含插件及每个插件的当前状态。
- 固定底部主操作：安装/更新/应用/切换/打开。
- 次操作：打开仓库、卸载（已安装项）。

### 3.3 筛选

- 探索：类型（全部/整合包/界面插件/逻辑插件），状态（全部/未安装/已安装/可更新）。
- 已安装：类型（全部/界面/逻辑/内置/APK），状态（全部/已启用/已停用/可更新）。
- 更新页不显示筛选按钮，只保留搜索。
- 搜索匹配名称、ID、说明、作者、标签、版本、来源；筛选条件同时生效。

### 3.4 插件源

- 独立底部面板：当前源、全部源列表、地址、当前标记、添加、删除自定义源。
- 选择源后关闭面板并刷新市场。
- 当前源的读取状态/错误显示在面板顶部；不伪造其它源的同步时间或数量。

## 4. 数据流

```text
PluginMarketViewModel (LiveData)
  ├─ presets / availableUiPlugins / items / uiPlugins / builtinPlugins / apkPlugins
  ├─ activePresetId / pendingUpdates / pluginStats
  ├─ loading / loadError / status / applyProgress
  └─ message / presetSwitch
        │
FragmentPluginMarket
  ├─ build state + filters + tab + query
  ├─ MarketListBuilder.build(...) -> List<MarketItem>
  ├─ MarketAdapter.submitList(...)
  └─ 用户动作 -> ViewModel 方法
        │
  MarketDetailSheet / MarketFilterSheet / MarketSourcesSheet / MarketGuideSheet
```

### 4.1 纯函数契约

`MarketListBuilder.build`：

- 前置：所有列表非 null；`query` 已 trim；`filters` 与 `tab` 已归一化。
- 后置：返回的 `MarketItem` 顺序稳定；同一输入得到同一输出；不读写 Android 状态。
- 不变式：任何行只出现一次；更新行只出现在“可更新”或“更新”分区。
- 违约：未知 tab 回退到探索；未知筛选值归一化为“全部”。

`MarketFilters.matches`：

- 前置：条目字段可为空。
- 后置：空查询匹配全部；查询大小写不敏感；仅接受该 tab 支持的筛选值。
- 不变式：搜索与筛选是 AND 关系。

## 5. 页面状态机

```text
IDLE
 └─ refresh() -> LOADING
LOADING
 ├─ 有缓存/已有列表 -> READY（保留内容，显示刷新指示）
 ├─ 成功且无内容 -> EMPTY
 └─ 失败 -> ERROR（显示错误与重试）
READY
 ├─ 搜索/筛选 -> READY
 ├─ 刷新 -> LOADING
 └─ 动作 -> READY（结果由 ViewModel 回调）
ERROR
 └─ 重试 -> LOADING
```

- 骨架只在 `LOADING && 没有可展示内容` 时出现。
- 有内容时刷新使用下拉指示，不遮挡列表。
- 空结果与读取失败使用不同文案和动作。

## 6. 模块与接口

### 6.1 `MarketItem` / `MarketListBuilder`

- 输入：tab、筛选、查询、预设、可用 UI 插件、已安装 UI 插件、逻辑插件、内置插件、APK 插件、当前预设 ID、APK 停用集合。
- 输出：分区/整合包/插件/内置/APK 行。
- 错误：输入为空时返回空列表或仅状态分区，不抛异常。

### 6.2 `MarketAdapter`

- 输入：`List<MarketItem>`、`Listener`。
- 输出：三种视图类型：分区、整合包、插件行。
- 契约：`submitList` 后不保留旧列表引用；动作与开关不触发根点击。

### 6.3 `MarketDetailSheet`

- 输入：详情模型（标题、版本、类型、描述、日志、元信息、插件状态、主/次动作）。
- 后置：点击主/次动作后关闭或执行回调；无动作时隐藏按钮。
- 不复用旧 `AlertDialog` 文本拼接。

### 6.4 `MarketSourcesSheet`

- 输入：源列表、当前源、状态文本。
- 输出：选择、添加、删除、刷新回调。
- 契约：默认源不可删除；删除自定义源需确认。

### 6.5 `MarketFilterSheet`

- 输入：tab、当前筛选。
- 输出：归一化后的 `MarketFilters`。
- 契约：取消不改筛选；应用立即刷新列表。

## 7. P0 验收

1. 市场内容为单列自适应行；有图标或字形、名称、说明、元信息。
2. 搜索框和筛选按钮固定在列表上方；滚动列表不消失。
3. 探索/已安装/更新分离；更新 tab 有数量徽标；指南移入更多菜单。
4. 探索按“可更新 → 整合包 → 全部插件”排序；已安装按更新/启用/停用分组。
5. 插件和整合包点击进入详情面板；整合包显示插件清单与状态。
6. 插件源有独立管理面板，支持选择、添加、删除和刷新。
7. 已安装动作与开关分层，不再把“已安装”画成主按钮。

## 8. P1 验收

1. 整合包切换进度内联显示，不再使用阻塞对话框。
2. 初始加载显示骨架；有内容刷新显示下拉指示。
3. 空结果、读取失败、重试、下拉刷新可用。
4. tab 徽标、状态 chip、信任/类型标识、更多菜单统一使用主题 token。
5. 动作最小触控高度 48dp；图标有 `contentDescription`；开关有插件名描述。
6. 详情/面板/列表动效使用短时淡入或滑动，不阻塞操作。

## 9. 验证

- 单元测试：`MarketListBuilder` 的搜索、筛选、分组、去重、更新分区。
- 构建：`:app:assembleDebug`。
- 静态检查：`:app:testDebugUnitTest`、`:app:lintDebug`。
- 设备：默认源、内置源、搜索、筛选、详情、源管理、切换整合包、更新 tab、空/错误状态截图。

## 10. 被否决方案

- 整体改为 Compose 重写：与现有 XML/BaseFragment 结构差异大，回归面过宽。
- 保留双列卡片只换配色：无法解决名称截断和动作拥挤。
- 把详情继续放在 `AlertDialog`：无法承载图标、插件清单和固定主操作。
- 把指南继续放第三个 tab：占用一级导航，降低探索/安装路径效率。
