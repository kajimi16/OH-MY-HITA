# OH-MY-HITA 0.10.1

## 本版重点

### HITA-L / HITA-CUTE 恢复

- 修复 HITA-L/CUTE 被 5 个插件 tabs 覆盖成 3 项底栏 + 5 页 pager 的回归。
- 今日、时间表重新使用内置插件 UI，不再显示“插件当前不可用”。
- 修复从 HITA-L/CUTE 切回 HITA Android 时，旧组合自动停用的 UI 被误判为用户停用而中止切换的问题。
- 修复旧预设 tab 兜底安装失败时未回滚 `TimetableService` 的路径。

### HITA Android 3.1.2 外观

- 底栏图标尺寸、选中字重、图标与文字间距按上游 `v3.1.2` 对齐。
- 抽屉“界面风格”“用户反馈”改用上游图标；抽屉行尺寸、颜色、字重对齐。
- 今日、时间表、助手标题，课表名称 chip，课程卡字号/行高，资讯通知字体与开发者署名对齐上游。
- 预设名称去掉“复刻”，统一为 `HITA Android 3.1.2`。

### 性能

- 消除主界面插件 tab 构建中的二次 SHA-256 扫描：`mainTabs()` 和 `resolveForCapability()` 复用同一安装快照。
- 交错冷启动基线（debug 模拟器，中位数）：`4578 ms → 2199 ms`，约下降 52%。
- 保留每个 APK 的完整性校验，没有引入基于文件元数据的哈希缓存。

### 其他

- 更新桌面图标。
- 增加五套界面风格材质。
- 插件 staging 移出 `cacheDir`。
- 修复 theta 空响应崩溃与 preset 安装细节。

## 安装

- 包名 `io.github.kajimi16.ohmyhita`
- 与旧版同签名，可直接覆盖安装
- 首次启动为插件化空壳，请从插件市场选择官方整合包
- minSdk 23

## 已知限制

- `eas-core` 的考试备忘录仍不提供官方考试时间。
- `user`、`theta`、`resource` 的 T2 页面仍为 preview。
- HITA-L/CUTE 的今日/时间表依赖宿主内置兼容层，后续若要严格空壳需迁移为独立 UI 插件。
