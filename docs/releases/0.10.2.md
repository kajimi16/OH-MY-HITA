# OH-MY-HITA 0.10.2

## 本版重点

### 首次启动引导

- 重做首次启动流程：先用“万物皆插件”介绍微内核与插件组合，再选择初始整合包。
- 新引导使用两步 Compose 页面：价值介绍 + 卡片式整合包选择。
- 显示推荐、使用中、插件数量、加载/失败/应用进度；不再使用 AlertDialog 列表。
- 从零开始、稍后选择、返回逻辑与已读状态独立处理；引导完成前不会先跳进旧壳。

### HITA_Lite 2.0

- 新增 HITA_Lite 旧版 UI 模块与 preset：三页、时间表管理/详情、事件弹层、成绩、
  考试、空教室、导入、搜索、教师、新闻、个人资料、关于/协议与小组件。
- 登录卡片改为 HITA-L 风格底部弹层：深圳 API 登录、网页登录回退、协议勾选与错误提示。
- 抽屉新增插件市场入口，可在 Lite 壳内切换整合包。
- Lite 小组件使用宿主服务渲染，不新增第二套数据源。

### 修复

- 时间表管理页补偿状态栏内缩，标题与基线对齐。
- 今日/时间表/功能中心壳层布局对齐 Lite 2.1。
- 登录服务缺失时不再静默无响应。

## 安装

- 包名 `io.github.kajimi16.ohmyhita`
- 与旧版同签名，可直接覆盖安装
- 首次启动为插件化空壳，请从引导页或插件市场选择官方整合包
- minSdk 23

## 已知限制

- HITA_Lite 时间表空态 SSIM `0.967311`，未达到 0.98；已按单页修复上限停止。
- 原版 Lite 固定数据 baseline 不可取得；部分子页与小组件固定态仍列为未验证。
- `eas-core` 的考试备忘录不提供官方考试时间。
- `user`、`theta`、`resource` 的 T2 页面仍为 preview。
